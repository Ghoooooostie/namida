# YouTube 移除与播客替换设计

日期：2026-10-03

## 目标

移除应用中的 YouTube 在线功能和用户入口，用现有播客入口替代原 YouTube 入口；保留本地视频播放和播客现有数据。

## 范围

- 移除 YouTube 页面、搜索、设置、账户、下载、缓存、备份和同步入口。
- 移除 YouTube 初始化、运行时调用、专用桩代码和 YouTube 专用依赖。
- 从默认库标签中移除 `LibraryTab.youtube`，保留 `LibraryTab.podcasts`。
- 读取旧库标签设置时，把旧的 YouTube 标签迁移为播客标签并去重。
- 保留本地视频播放，不再提供 YouTube 在线播放或 YouTube 链接解析入口。
- 播客继续使用独立的设置、历史、进度、收藏、订阅和下载文件。

## 数据处理

YouTube 设置、历史、播放列表、订阅、缓存和统计文件不删除，也不迁移到播客；应用停止读取、写入、备份和同步这些文件。旧队列或旧记录中遇到 YouTube 项目时跳过，避免恢复过程崩溃。

播客数据不复用 YouTube 文件格式。现有播客的 `PodcastSourceType.youtube` 旧值在读取时按普通手动 RSS 来源处理，避免继续依赖 YouTube 类型。

## 兼容性

- 旧设置中的 YouTube 库标签迁移为播客标签。
- 旧 YouTube 队列、历史和同步消息不再恢复。
- 不删除用户目录中的旧文件。
- 本地视频、音乐、字幕、Anki、AI 字幕和播客功能保持可用。

## 验证

- 运行 Dart 静态分析和现有测试。
- 构建 Android Debug 包；设备可用时安装 Debug 包。
- 检查应用启动、库标签、播客入口、本地视频播放和旧设置加载。
